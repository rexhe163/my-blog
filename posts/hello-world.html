你好，世界：我的第一篇博客

2026-10-27

这是本博客的第一篇文章。为什么要写博客？因为写作是最好的思考方式——把学到的东西讲清楚，才算真的懂了。

这个博客是怎么搭的

技术栈非常简单：

  • 纯静态页面：HTML + CSS + 少量 JS，没有框架、没有构建步骤
  • GitHub：存放源码，作为内容管理后台
  • Cloudflare Pages：免费托管，push 到 GitHub 后自动部署上线

如何发布新文章

  1. 在 posts/ 目录下新建一个 HTML 文件（可以复制现有文章作为模板）
  2. 在首页 index.html 的文章列表里加一张卡片
  3. 提交并推送到 GitHub，Cloudflare 会自动更新网站

就这么简单。希望这里能沉淀下我未来几年的思考。
